AuteurStudio

Open your local Studio.

This lightweight desktop shell starts the Auteur Studio server from an existing project folder. Rendering stays local; no cloud account is involved.

Checking for a running Studio…
Node 22+Runs the Studio API and pipeline.
FFmpegRenders and mixes audio.
ChromeHyperFrames capture.

Run pnpm install once in the project folder. This installer does not bundle Node, FFmpeg, Chrome, or the project itself. If the server is already running, the shell opens it directly.
